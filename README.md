# 🤖 IRON-AI: RAG-Powered Calisthenics Assistant

> A modern, full-stack AI Assistant built specifically for Calisthenics enthusiasts, combining Retrieval-Augmented Generation (RAG) with a high-performance Groq LLM backend and an immersive Cyberpunk-themed UI.

---

## 🌟 Key Features

* **RAG Architecture**: Leverages local domain knowledge (`Knowledge.txt`) to deliver accurate, context-aware Calisthenics training advice.
* **Ultra-Fast LLM Inference**: Powered by the **Groq API** for near-instant response generation.
* **FastAPI Backend**: Clean, asynchronous Python REST API handling query embedding, context retrieval, and model responses.
* **Cyberpunk Frontend**: Responsive, futuristic user interface for seamless real-time interactions.
* **Safety & Security**: Key management designed with environment placeholders to keep credentials secure.

---

## 🛠️ Tech Stack

* **Backend**: Python 3.13, FastAPI, Uvicorn
* **AI & RAG**: Groq API, Custom Semantic Matching Logic
* **Frontend**: HTML5, CSS3 (Cyberpunk Theme), JavaScript (Fetch API)
* **Version Control**: Git, GitHub
